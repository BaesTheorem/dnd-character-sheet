BaseASIRacialMagicalMisc
Final score = Base + ASI + Racial + Magical + Misc. The sheet shows only the total and modifier.

Ability Score Improvements & Feats

Your class grants an Ability Score Improvement at certain levels — for each, take either an ASI (+2 to one ability, or +1 to two) or a Feat. Some races (Variant Human, Custom Lineage) also grant a feat.

Loads any book straight from your local 5etools server (works offline; keep that server running). Loaded books are remembered in this browser. To refresh an already-loaded book's data, use the Reload picker (it appears once a book is loaded).

A browser can't overwrite the open file, so Save data file downloads an updated copy (with every loaded book baked in) — keep it / replace your sheet with it to make the books permanent. Clear loaded books forgets everything loaded in this browser and reverts to the data baked into this file.
