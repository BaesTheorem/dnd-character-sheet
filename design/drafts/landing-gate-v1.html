What opens when you double-click the file.

  1. Download the file

    Download the file 16 MB

    Character Sheet v2.169.0.html · updated October 27, 2026

  2. Open it

    Double-click the file in your Downloads folder. It opens in your browser, like a web page that lives on your computer.

  3. Keep it

    The sheet autosaves in your browser while you play. Press Save any time and you get a new copy of the file with every character inside, ready to back up or move to another computer.
